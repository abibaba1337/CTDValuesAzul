# Azul Values — установка на Vercel

Сайт со значениями предметов, калькулятором трейдов и сигнами.
**Все посетители** видят сайт и пользуются калькулятором. **Править** значения, Demand, Stability и проценты сигн можешь только ты, по паролю.

---

## Что внутри ZIP

| Файл | Зачем |
|---|---|
| `index.html` | Сам сайт (дизайн, калькулятор, сигны, иконки) |
| `api/data.js` | Отдаёт всем посетителям сохранённые правки |
| `api/login.js` | Проверяет пароль админа |
| `api/save.js` | Сохраняет правки (только с паролем) |
| `api/status.js` | Диагностика настройки |
| `api/_lib.js` | Общий код (база, проверка пароля) |
| `package.json` | Служебный файл |

---

## Шаг 1. Залей проект на Vercel

Нужен аккаунт на vercel.com (бесплатного хватает).

### Вариант А: через GitHub (проще, без командной строки)
1. Распакуй ZIP на компьютере.
2. Зайди на github.com и создай новый репозиторий (**New repository**, можно Private).
3. В репозитории нажми **Add file → Upload files** и перетащи **всё содержимое папки**: `index.html`, `package.json`, `README.md` и папку `api`. Нажми **Commit changes**.
4. На vercel.com нажми **Add New → Project**, выбери этот репозиторий, **Import**.
5. Ничего не меняй в настройках и нажми **Deploy**.

### Вариант Б: через командную строку
1. Установи Node.js (nodejs.org).
2. В папке проекта выполни:
   ```
   npm i -g vercel
   vercel
   ```
   Отвечай на вопросы (везде Enter). В конце получишь ссылку.

После деплоя сайт уже откроется, но править значения ещё нельзя. Дальше шаги 2 и 3.

---

## Шаг 2. Подключи базу данных (хранит твои правки)

1. В Vercel открой свой проект и перейди на вкладку **Storage**.
2. Нажми **Create Database** и выбери **Upstash for Redis** (бесплатного тарифа хватит).
3. Создай базу и нажми **Connect to Project**, выбери свой проект.
4. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`. Вручную ничего вводить не нужно.

---

## Шаг 3. Задай пароль администратора

1. Проект → **Settings → Environment Variables**.
2. Добавь переменную:
   - **Name:** `ADMIN_PASSWORD`
   - **Value:** твой пароль (длинный, например 16+ символов, не тот, что используешь на других сайтах)
   - Environments: оставь все галочки.
3. Нажми **Save**.

---

## Шаг 4. Передеплой (обязательно!)

Переменные из шагов 2 и 3 начинают работать только в **новом** деплое.

Проект → вкладка **Deployments** → у последнего деплоя нажми **⋯ → Redeploy**.

---

## Шаг 5. Проверь, что всё настроено

Открой `https://ТВОЙ-САЙТ.vercel.app/api/status`. Должно быть:
```
{"adminPasswordSet":true,"redis":"ok"}
```
Если `false` или `not connected`, вернись к шагам 2–4.

---

## Как править значения и сигны

1. Открой `https://ТВОЙ-САЙТ.vercel.app/#admin`
2. Введи пароль. Появятся кнопки **«✎ Править»** и **«Выйти»**.
3. Нажми **«✎ Править»**:
   - на вкладке **Values** у каждого предмета можно менять Value, Demand, Stability;
   - на вкладке **Signs** можно менять процент каждой сигны.
4. Внизу появится панель **«Изменений: N»**. Нажми **«Опубликовать»**.
5. Готово. Остальные посетители увидят новые значения при заходе на сайт, а у тех, кто уже сидит на сайте, всё обновится в течение минуты.

Пароль хранится только во вкладке браузера. Закрыл вкладку, и войти нужно заново.

---

## Почему другие не смогут ничего менять

- Для обычных посетителей кнопки «Править» нет вообще. Она появляется только после ввода пароля.
- Главная защита стоит на сервере: `api/save.js` не сохранит ничего без правильного пароля (проверка при каждом сохранении). Даже если кто-то найдёт адрес API и отправит запрос напрямую, он получит ошибку 401.
- Пароль лежит только в настройках Vercel, в коде сайта его нет.
- Попытки ввода пароля ограничены: не больше 10 в минуту с одного адреса.
- Сервер проверяет присланные данные: числа в допустимых пределах (Demand от 0 до 10, Stability только из списка).
- Калькулятором, поиском, сортировкой и сигнами все пользуются свободно, пароль на них не влияет.

**Чтобы сменить пароль:** Settings → Environment Variables → измени `ADMIN_PASSWORD` → **Redeploy**.

## Как добавить новые предметы или новых людей в сигны

Правки через сайт меняют только Value, Demand, Stability и проценты. Новые предметы и новые сигны добавляются в код:
- предметы: массив `RAW` в `index.html` (формат: `["Название","Редкость",значение,спрос,"Стабильность"]`);
- сигны: массив `SIGNS` в `index.html` (формат: `["Имя","Ник",процент]`), новых добавляй **в конец списка**, чтобы не сбить уже сохранённые правки;
- иконки: объект `IMG`, ключ это точное название предмета.

После правки файла закоммить его на GitHub (или запусти `vercel --prod`), и Vercel обновит сайт. Уже сохранённые правки значений останутся.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Окно пароля пишет «Сервер не настроен» | Открой `/api/status` и пройди шаги 2–4 (база и пароль, потом Redeploy) |
| «Неверный пароль» | Пароль должен совпадать с `ADMIN_PASSWORD` в Vercel. Если менял, нужен Redeploy |
| «Слишком много попыток» | Подожди минуту |
| Кнопки «Править» нет | Открывай именно ссылку с `/#admin` на конце |
| После «Опубликовать» ошибка | Проверь `/api/status`: `redis` должен быть `ok` |
| Значения не обновились у других | Пусть обновят страницу (Ctrl+F5). Автообновление идёт раз в минуту |
